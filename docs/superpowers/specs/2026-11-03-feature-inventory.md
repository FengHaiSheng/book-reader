# 阅微 · 功能清单（现状沉淀）

- 日期：2026-11-03
- 状态：对照当前代码与 IPC 白名单整理（非愿景稿）
- 产品名：阅微
- 定位：纯本地桌面阅读器 —— 无账号、无云同步、无遥测；AI 为 BYOK，不配置也能完整读书

本文档描述**当前已落地**的能力。早期设计稿（仅 EPUB）与 README 中个别表述若与代码不一致，以本清单为准。

---

## 0. 产品硬规则（贯穿全局）

1. **AI 永不后台自动调用** —— 所有模型请求须由用户显式触发或确认。
2. **能力降级要明说** —— 厂商不支持 embedding / 结构化输出等时，界面说明降级结果，不静默失败。
3. **渲染进程零能力** —— 文件系统、解析、SQLite、AI、密钥均在主进程；preload 仅暴露具名白名单（见 `shared/ipc.ts` → `API_SHAPE`）。

**明确不做**：账号与云同步、多端、独立向量数据库产品、自动更新、朗读 / TTS、扫描版 PDF OCR、打开书即自动全书 AI 分析。

## 2. 书架（书库）

### 2.1 导入

- **格式**：EPUB、PDF、TXT、MOBI / AZW、AZW3（KF8）、FB2、HTMLZ、漫画 CBZ / CBR（`BOOK_EXTENSIONS`）
- **阅读模式**：文字书 `text`（分栏排版）；漫画 `comic`（整页图片）
- **入口**：选择文件导入、选择文件夹扫描导入、拖放多文件到书架页
- **行为**：原文件复制进书库目录；**sha256 去重**（重复导入返回已有书）；导入进度事件（hash / extract / store）

### 2.2 浏览与管理

- 网格 / 列表双视图；封面装帧式展示
- 排序：最近阅读 / 书名 / 加入时间
- 侧栏状态筛选：全部 / 在读 / 已完成 / 未开始（含计数与书库体积汇总）
- **标签**：创建、重命名、删除、给书打标；侧栏按标签筛选；书名搜索可匹配标签
- **搜索**：输入过滤书名 / 作者 / 标签；显式「搜正文」走全库 FTS（⌘K / Ctrl+K 聚焦）；结果为壳层顶部浮层（可收起/关闭、10 条分页），进阅读后仍可展开点下一条
- 打开书籍进入阅读器；可从笔记 / 搜索结果带章节 + CFI 定位打开
- 删除书：二次确认；笔记、高亮、进度一并删除

## 3. 阅读器

### 3.1 文字书（text）

- 单章 iframe + CSS 多栏横向翻页（`translateX`）
- 进度与标注定位以 **CFI** 为准；进度持久化
- 窗口 ≥ 约 1900px 自动对开双页；**版心吃满纸面可用宽**，字号不参与算行宽
- **排版偏好**（设置页 + 运行时）：宋 / 黑、字号 15–32、行距 1.5–2.2、亮 / 暗主题
- 窄窗口降字号时界面明说实际字号，不静默降级
- **目录**（侧栏）：嵌套章节跳转
- **书签**：当前页添加 / 移除；列表跳转；摘录预览
- **书内查找**：FindBar + FTS5 bigram，本地、不调模型；结果上下条导航与定位
- 退出阅读确认弹窗（避免误切导航丢上下文）

### 3.2 漫画（comic）

- CBZ / CBR 按图片页整页显示
- 单页 / 双页切换（宽屏默认可双页）
- 方向键、空格、点左右半屏翻页

### 3.3 划词与标注

划词浮条（过长有字数上限提示）：

- 四色高亮
- 写笔记（批注）
- 复制
- **解释 / 翻译 / 问 AI**（打开 AI 面板；解释 / 翻译可直接发送，问 AI 只预填）

已有高亮浮层：改色、编辑批注、查看 / 删除钉住的 AI 笔记、删除高亮。

实现要点：

- 高亮用 **CSS Custom Highlight API**（不插入 `<mark>`）；环境不支持时明说「只保存不显示」
- 可把 AI 回答 **钉到划线**（解释 / 翻译 / 问答来源），笔记页可筛「有 AI 笔记」

---

## 4. 笔记页

- 跨书汇总高亮 / 批注；按书分组，分组可折叠
- 筛选：全部 / 仅高亮 / 仅有批注 / 有 AI 笔记；按书；关键字（划线 + 批注文）
- 右侧上下文面板：不回书也能看原文上下文
- 点击笔记可跳回阅读定位
- 就地改批注、删除笔记、删除挂接的 AI 笔记
- **导出**（预览后落盘）：
  - 范围：全部或当前筛选结果
  - 格式：Markdown / Anki / HTML
  - 选项：含批注、含位置、含上下文、含 AI 笔记

## 5. AI 能力（BYOK）

### 5.1 配置（设置 → 模型）

- 厂商：DeepSeek / 通义千问 / 智谱 GLM / Kimi（OpenAI 兼容）
- API Key：系统 `safeStorage`；可测连通、清除
- 模型选择与能力状态展示；不支持的能力明说降级

### 5.2 对话面板

- 划词问答 / 解释 / 翻译；流式输出；引用可回跳
- 发送前 **token 预估**；回答展示本次用量
- 历史按书 / 章作用域；可清空
- 单通道串行；切章 / 关面板 / 取消即中断
- 面板宽度可拖，写入偏好
- 「记到划线」把回答钉到高亮

### 5.3 结构化任务（分析 Tab）

| 任务 | 行为 |
|---|---|
| 本章小结 | 本章结构化小结；结果缓存复用 |
| 全书要点 | 逐章请求；已有小结章复用 |
| 关键词与概念 | 基于小结再请求；可触发前置全书要点 |
| 思维导图 | **不调模型**：按章节重组关键词结果 |

另支持显式 **向量索引构建 / 取消 / 状态**（中文检索默认可走 FTS5 bigram，不依赖 embedding）。

## 6. 设置页其余模块

### 6.1 阅读偏好

见 §3.1；与阅读器共用同一套 `ReadingPrefs` / `PREFS_LIMITS`。

### 6.2 阅读统计

- 今日 / 近 7 天 / 累计时长
- 年度热力图
- 阅读中累计秒数写入本地库；结算失败时提示残差重试

### 6.3 数据

- 数据目录占用统计；打开书库 / 备份 / userData 目录
- 备份列表
- **整库导出**（不含 API Key）
- **整库导入恢复**（覆盖前自动备份 DB；密钥不在包内）
- 清理运行日志并整理 DB（不动书与笔记）

## 7. 本地数据层（能力视角）

| 域 | 能力 |
|---|---|
| SQLite | 书、章、chunks、进度、高亮、书签、标签、AI 结果 / 消息、阅读时长等 |
| FTS5 | 书内 / 全库正文检索（bigram） |
| 书库目录 | 每书独立目录存原文件与衍生资源 |
| 密钥 | 与书库分离；导出包不含密钥 |
| 自定义协议 | 如 `epub://` 按需取章正文 |

## 9. 功能地图（按用户路径）

```
启动
 ├─ 书架：导入 / 拖放 / 标签 / 状态筛选 / 搜书名 / 搜正文 → 打开书

 ├─ 文字：翻页 · 目录 · 书签 · 查找 · 排版自适应
 ├─ 漫画：单双页 · 键鼠翻页
 ├─ 划词：高亮 · 批注 · 复制 · AI
 └─ AI 面板：对话 · 分析任务 · 钉到划线 · 索引
```
