# 阅读壳层侧栏 · 设计文档

- 日期：2026-10-26
- 状态：待用户确认后写实现计划
- 范围：去掉阅读顶栏「返回书架」；壳层侧栏在阅读时常驻并收成图标轨；目录/书签并入侧栏；所有离开阅读路径统一确认

## 0. 摘要

进入阅读后不再整页卸掉壳层。`App` 始终保留侧栏：阅读时自动收成约 **56px 图标轨**（可手动展开），退出阅读后强制回到展开。阅读顶栏去掉「返回书架」；独立 `TocPanel` 取消，目录/书签在侧栏**展开态**中显示。凡离开阅读（侧栏三项、Esc、缺书态退出、漫画退出等）一律先确认，确认后再 flush 进度并跳转。

---

## 1. 目标与非目标

### 1.1 目标

1. 去掉阅读顶栏左侧「返回书架」按钮（文字书、漫画、缺书态同理）。
2. 壳层侧栏（书架 / 笔记 / 设置）在阅读时仍可见：默认图标轨，可手动展开/收起。
3. 进入阅读 → 自动收起；退出阅读 → 自动展开（不持久化阅读中的临时展开）。
4. 阅读时目录/书签并入壳层侧栏展开态，不再占用阅读主区左侧固定 248px `TocPanel`。
5. 所有离开阅读的入口统一确认对话框；确认后保存进度并离开。

### 1.2 非目标

- 不改 AI / 排版 / 查找面板的开闭与宽度逻辑。
- 不把「查找 / AI / 排版」挪进侧栏。
- 不做侧栏图标的自定义或拖拽排序。
- 不持久化「阅读中手动展开」偏好；也不引入与阅读无关的全局侧栏折叠偏好（非阅读始终展开）。
- 不改标签筛选、书库状态筛选在**非阅读**侧栏里的既有行为。
- 不在本次做窗口 &lt;840 的壳层自适应（Electron `minWidth` 仍为 840）；本次只落实阅读态的图标轨。

## 2. 用户流程

### 2.1 进入 / 离开阅读

1. 书架开书 → 主区换成阅读器；侧栏自动收成图标轨；顶栏无「返回书架」。
2. 阅读中点侧栏展开控件 → 侧栏拉到约 248px，上方仍是三项导航（带文案），下方是「目录 / 书签」。
3. 再点收起 → 回到图标轨。
4. 点「书架 / 笔记 / 设置」任一图标（或展开后的文案项）→ 弹出确认 → 确认后退出阅读并切到该页；取消则留在阅读。
5. 按 Esc（查找未开时）→ 同样确认 → 确认后退出阅读，回到进入前所在的壳层页（`page` 状态本就未改）。
6. 退出成功后侧栏强制展开，并恢复该页的上下文列表（书架页的标签/状态等）。

### 2.2 确认文案

- 标题：`离开阅读？`
- 正文：
  - 目标为某壳层页：`进度会自动保存。确定离开并前往「{书架|笔记|设置}」吗？`
  - Esc / 无明确目标页：`进度会自动保存。确定离开阅读吗？`
- 操作：`取消`（默认焦点）/ `离开`
- 确认框打开时 Esc 或点遮罩 = 取消离开，不退出阅读。
- 实现用现有 `Modal`（不用 `window.confirm`），与应用内其它占注意力操作一致。

### 2.3 查找与 Esc 优先级（不变再加一层）

1. 查找开着 → Esc 先关查找（现有行为）。
2. 离开确认开着 → Esc 关确认。
3. 否则 Esc → 请求离开阅读（出确认）。

## 3. 布局

### 3.1 壳层结构（始终）

```
.app
├── TitleBar          // 仅非阅读时显示（避免与阅读顶栏叠两层）
└── .body
    ├── Sidebar       // 始终挂载
    └── main          // 非阅读：各 Page；阅读：ReaderPage
```

废除「`if (reading) return <ReaderPage />` 整页替换」。阅读只替换 `main` 内容。

### 3.2 侧栏宽度

| 状态 | 宽度 | 内容 |
|---|---|---|
| 非阅读 | 248px（现有） | 导航 +（书架页）书库筛选/标签/页脚 |
| 阅读·收起 | 56px | 三项导航图标 + 展开控件 |
| 阅读·展开 | 248px | 三项导航（图标+文案）+ 收起控件 + 目录/书签 |

宽度常量与 `.uicraft.md` 的 56px 图标栏对齐。侧栏是 `.body` 里与主区并列的壳层控件，**不在** `ReaderPage` 内部；主区（`.content` / `.reader`）的宽度已经是「窗口减去侧栏」后的剩余。因此版心/`computeLayout` **不再扣除**阅读区内的 `TOC_WIDTH`——目录离开阅读器后，这项扣减会变成重复。侧栏收起/展开会改变主区宽度，现有 resize 观察即可重算版心。

### 3.3 阅读顶栏

- 保留：书名、章节（文字书）、翻页、页码、查找 / AI / 排版（漫画：双页等既有控件）。
- 删除：「返回书架」。
- macOS 红绿灯：阅读时落在窗口左上，与侧栏顶部重叠区域不可点；侧栏顶部为红绿灯留出与现有 `BAR_PAD_LEFT` 等效的不可点/留白区。阅读顶栏不再需要为红绿灯单独大幅左垫（侧栏已占左缘）；具体像素在实现时与 `chrome.ts` 对齐，避免双重留白。

### 3.4 阅读主区

- 不再渲染独立 `.toc` / `TocPanel`。
- 文字书：展开侧栏时在侧栏内渲染原目录/书签 UI（可复用 `TocPanel` 内容，换容器样式以融入 `.sidebar`）。
- 漫画：无目录/书签区块；展开侧栏只显示导航文案。
- 缺书态：主区提示文案；退出仍走统一确认（侧栏或 Esc）。

## 4. 状态与数据流

### 4.1 App 状态

| 状态 | 说明 |
|---|---|
| `page` | `library \| notes \| settings`；阅读中也可被「确认离开」改写 |
| `reading` | `ReadingTarget \| null` |
| `sidebarCollapsed` | 仅阅读中有意义；进入阅读时置 `true`；退出时置 `false`；阅读中由用户切换 |
| `exitDialog` | `null \| { to: PageId \| null }`；`to === null` 表示 Esc 类「只退出、不改 page」 |

### 4.2 离开阅读的单一入口

`requestExit(to: PageId | null)`：

1. 若已在确认中，忽略重复打开。
2. 设置 `exitDialog = { to }`。
3. 用户确认 → 调用阅读器暴露的 `flushAndExit()`（现有 `exit`：flush 偏好、进度、时长）→ `setReading(null)` → 若 `to !== null` 则 `setPage(to)` → `sidebarCollapsed = false` → 关闭对话框。
4. 用户取消 → 只关对话框。

所有 UI / 快捷键不得再直接 `setReading(null)` 或调用未包装的 `onExit`。

### 4.3 目录数据如何进侧栏

阅读器仍是章节/书签的唯一真相来源。采用 **React Context**（由 `ReaderPage` 在挂载阅读时提供）：

- 提供：章节列表、当前章、书签列表、当前页书签、以及 `onSelectChapter` / 书签增删跳转回调。
- `Sidebar` 在 `reading != null && !sidebarCollapsed` 时消费该 Context，渲染目录/书签。
- 漫画或尚未开完书：Context 为空/不适用 → 侧栏不显示目录区块。

不把整棵章节树长期抬到 `App` 状态，避免开书 effect 与壳层双重持有。

### 4.4 导航高亮

- 非阅读：现有 `nav-item--active` 跟 `page`。
- 阅读中：三项均不高亮为「当前页」（内容是书，不是三个壳层页之一）；点击仍触发 `requestExit(该页)`。

## 5. 组件改动边界

| 单元 | 职责 |
|---|---|
| `App` | 常驻侧栏；持有 `sidebarCollapsed` / `exitDialog`；`requestExit`；阅读时不挂 TitleBar |
| `Sidebar` | 支持 `collapsed`；阅读态隐藏标签/状态/页脚；展开时挂目录插槽；展开/收起控件 |
| `ReaderPage` / `ComicReader` | 去掉返回按钮与独立 Toc；提供 Context；`onExit` 改为受控的 flush 回调供确认后调用 |
| `TocPanel` | 抽成可放进侧栏的内容；去掉自身假定的 `.toc` 固定宽外壳，或加 `variant="sidebar"` |
| `Modal` | 复用为离开确认（正文 + 取消/离开按钮） |
| `layout.ts` | 去掉（或停用）阅读区内对 `TOC_WIDTH` 的扣除；主区宽度已不含壳层侧栏 |

## 6. 错误与边界

- 确认后 flush 失败：仍关闭阅读（与现网 `exit` 尽力保存一致）；不因确认框改变保存语义。
- 快速连点侧栏多项：只保留一份 `exitDialog`；以打开对话框时的 `to` 为准，打开期间忽略新的 `requestExit`，避免文案抖动。
- 开书中（book 尚未就绪）：侧栏仍可请求离开；确认后照常清 `reading`。
- 主题切换等阅读内操作不受影响。

---

## 7. 测试要点

1. 开书 → 侧栏为图标轨；顶栏无「返回书架」；正文变宽（无双左栏）。
2. 手动展开 → 可见目录并跳章；收起 → 图标轨；退出后侧栏展开且为书架上下文。
3. 图标点「笔记」→ 确认取消仍在读；确认离开到笔记页且 `reading === null`。
4. Esc：查找开着只关查找；否则出确认；确认中 Esc 取消。
5. 漫画：无目录区块；退出同样确认。
6. 缺书态：可经侧栏/Esc 确认离开。
7. 版心/对开：侧栏收起与展开切换后翻页几何正确（resize 观察者仍触发）。
