# 全库正文搜索结果浮层 · 设计文档

- 日期：2026-11-03
- 状态：按先前约定直接落地（用户授权跳过分段确认）
- 范围：搜正文结果改为壳层顶部浮层；进阅读后仍可浏览/点选；统一分页；搜正文与输入框合成一组
- 配套：
  - [阅读壳层侧栏](./2026-10-26-reading-shell-sidebar-design.md)
  - 现有全库 FTS：`library.searchAll`、书名筛选与正文搜索分离

---

## 0. 摘要

全库正文搜索结果从「嵌在书架页、点命中即卸掉」改为 **App 级顶部浮层**：可展开 / 收起 / 关闭；点命中进入阅读后浮层 **自动收成细条**，仍可展开点下一条。整次结果统一分页（10 条/页）。标题栏输入与「搜正文」合成一组控件。

---

## 1. 目标与非目标

### 1.1 目标

1. 点命中进阅读后仍能看到本次搜索结果，可继续点下一条（不必只能选一次）。
2. 结果以顶部浮层呈现：展开看列表；收起成细条；关闭才丢掉结果（输入框文字保留）。
3. 进阅读时浮层自动收成细条；只有主动关闭才消失。
4. 去掉「每书只露 5 条」；改为整次结果统一分页，每页 10 条。
5. 「搜正文」与左侧输入框视觉合成一组。

### 1.2 非目标

- 不在阅读页提供新的「再搜一次」入口（改词须回书架）。
- 不改 FTS / `searchAll` 语义与 LIMIT（仍默认最多 60 条）。
- 不改书内查找（FindBar）。
- 不做搜索结果跨会话持久化（关浮层或重启即无）。

---

## 2. 用户流程

1. 书架标题栏输入关键词 → 回车或点「搜正文」→ 浮层展开，显示分页结果。
2. 点一条命中 → 打开对应书并定位摘录；浮层收成细条。
3. 点细条「展开」→ 再点另一条 → 跳转并再次收成细条。
4. 「收起」：细条保留结果与页码。「关闭」：丢掉结果；输入框文字保留。
5. 书架上 Esc：清空输入 + 关掉正文结果（与现行为一致）。
6. 阅读中 Esc：查找开着 → 先关查找；浮层展开 → 先收起浮层；否则 → 离开确认。

---

## 3. 布局与状态

### 3.1 挂载

- 状态与浮层挂在 `App`（或壳层组件），不随 `LibraryPage` 卸载。
- 浮层盖住主区、不盖侧栏；书架时在标题栏下，阅读时在阅读顶栏下。
- 展开时列表盖住正文舞台；离开确认 Modal 仍高于浮层。

### 3.2 状态字段

| 字段 | 说明 |
|---|---|
| `query` | 标题栏输入（书名筛选）；关闭结果后仍可保留 |
| `bodyQuery` / `hits` / `busy` / `error` | 最近一次显式正文搜索 |
| `open` | 展开 / 收起 |
| `page` | 0-based 页码；新搜索重置为 0 |

关闭：清 `hits`/`bodyQuery`/`error`，`open=false`，**保留** `query`。  
Esc（书架）：关闭结果并清空 `query`。

### 3.3 分页

- `PAGE_SIZE = 10`；对扁平 `hits` 切片后再 `groupHitsByBook`（页内仍可显示书名小标题）。
- 页码控件：上一页 / 下一页 +「第 n / N 页」。

---

## 4. 标题栏合成

输入框与「搜正文」共用一组边框（右侧为按钮），视觉上是一个控件；分隔线后再放导入 / 标签。行为不变：输入只滤书名；回车与按钮才发 FTS。

---

## 5. 测试要点

- e2e：搜正文 → 点命中进阅读 → 浮层细条仍在 → 展开再点另一条仍能跳转；关闭后细条消失且输入仍在；书架 Esc 清空。
