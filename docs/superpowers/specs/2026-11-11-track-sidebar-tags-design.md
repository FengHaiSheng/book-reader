## 0. 摘要

**标签保持原样**（侧栏筛选、＋标签、标签管理语义不变）。存在 active 学习脉络时，书架工具栏增加 **按列表 | 按脉络**：按脉络时主区按能力树分节列书（书挂在直接挂载节点下；空节点仍显示节；末节为未归类）。标签 / 状态 / 书名搜索与分节叠加。

新书在有 Track 时走 **本地规则预归位**（不调模型）：高置信写 `source=local`，中置信待确认（确认后 `user`），低置信留未归类；只处理零挂载书。脉络页提供「归位未归类」。

---

## 1. 目标与非目标

### 1.1 目标

1. 有 active Track 时，书架主区可切换「按脉络」树形分节视图；默认仍为现有「按列表」（网格/列表排布不变）。
2. 侧栏标签、书卡片「＋标签」、标签管理：**零改语义**。
3. 按脉络时，状态 × 标签 × 书名搜索先过滤书集，再分节；空节点节保留以表达覆盖缺口。
4. 导入成功与「归位未归类」触发本地三档匹配；AI 挂载仍只走显式 `track.build`。

### 1.2 非目标

- 用脉络覆盖 / 归档标签；侧栏改渲染脉络树；「＋标签」改为挂节点
- `tags.archived`、`tags.parent_id`、物化脉络标签树
- 书架卡片上的次要「挂到节点」入口（可下一刀）
- 导入、打开应用自动调模型；多 Track；笔记按节点筛选
- 待确认队列持久化（可下一刀）

### 1.3 沿用硬规则

1. AI 永不后台自动调用。
2. 能力降级要明说。
3. 渲染进程零能力；密钥与模型在主进程。
4. 单通道串行；中断即 Abort；BYOK 展示用量。

## 2. 概念模型

| 对象 | 含义 |
|---|---|
| 标签 | 书架筛选与 chip；与脉络无关，本刀不改 |
| Track / Node | 能力树；「按脉络」分节的数据源 |
| NodeBook | 书 ↔ 节点；`source` 为 `ai` \| `user` \| `local` |
| 按列表 | 现有书架主区（可网格/列表排布） |
| 按脉络 | 同一过滤书集按节点树分节的主区视图 |
| 未归类 | 非 DB 节点：零挂载的书；脉络视图末节 |
| 待确认 | 本地匹配中置信结果；确认前不落库 |

挂载是书在脉络中的唯一归属真相；标签不是挂载的投影，也不是挂载的输入信号。

## 3. 书架主区交互

### 3.1 视图切换

- 有 active Track：工具栏提供 **按列表 | 按脉络**（与网格/列表排布控件分离：排布是 card layout，脉络是分组模式）。
- 无 Track：不出现该切换；主区与现网一致。
- 切换只影响主区呈现，不改侧栏、不改库数据。
- 可持久化 `library.groupBy: 'list' | 'track'`；无 Track 时强制按列表。

### 3.2 按脉络 · 布局

- 按 `track_nodes` 树序分节：depth 1 主节标题，depth 2/3 下级标题。
- 每本书只出现在**直接挂载**的节点节下（不在祖先节重复铺书）。
- 节标题旁可显示本节点直挂数量（过滤后）。
- **空节点**：仍显示节标题 + 短空态（如「暂无挂书」）。
- **未归类**：树后固定一节；若过滤后无书可隐藏该节。
- 一书多挂：可在多个节点节各出现一次。
- 卡片样式复用现有网格/列表；节间用标题分隔，不套卡片容器。
- 根目标不单独占一节；目标名可在工具栏脉络模式旁作上下文。

### 3.3 筛选叠加

1. 先得到与现网相同的书集：状态 × 标签 × 书名搜索（书名搜索仍匹配标题、作者、标签名；本刀不强制加节点名，实现计划若加节点名匹配须单测锁住且不替代标签匹配）。
2. 再按挂载分到各节点节；过滤后某节点无直挂书 → **仍显示空节**。
3. 点书打开阅读器，行为与按列表相同。

### 3.4 挂载编辑

- 书架 **不** 改「＋标签」；改挂载在脉络页（手改、待确认、「归位未归类」）。
- 问缺 / 重生骨架仍只在脉络页。

## 4. 新书本地归位

### 4.1 触发（均不调模型）

1. 导入成功且存在 active Track：对本批**零挂载**新书跑匹配。
2. 脉络页「归位未归类」：对当前零挂载书批量再跑。

### 4.2 信号

- 书：标题、作者、目录标题前若干条。
- 节点：`title` + `summary`。
- 不使用标签名参与打分。

### 4.3 三档

| 档 | 行为 |
|---|---|
| 高置信 | 唯一强命中 → 写挂载，`source=local` |
| 中置信 | 多候选或中等分 → 待确认；确认后写挂载，`source=user` |
| 低置信 | 不挂，留未归类 |

- 偏好最深匹配节点；祖孙多命中只留最深；无关多节点且均极强时可多挂。
- 阈值与规则在实现计划中给默认值并用单测锁住。

### 4.4 保护

- 只处理零挂载书；已有任意挂载的书不改写，计入 `skipped`。
- 不存在「清除旧 local 再写」路径；改已挂之书只走脉络页手改 / `setBookLinks`（`user`）。

### 4.5 反馈

- 导入后轻提示：`已归位 N · 待确认 M · 仍未归类 K`；M>0 可「去确认」（脉络页待确认区）。
- 「归位未归类」结束同样汇总；无费用确认框。

### 4.6 不做

- 导入绑 AI 挂载；打开应用后台扫描；低置信自动挂。

## 5. 存储与 IPC

### 5.1 存储

```text
track_node_books.source
  -- 既有 ai | user；本刀扩展 local

tags / book_tags
  -- 不改表结构；不成树归档；不物化脉络树
```

待确认不落库；删书只删挂载行（沿用）。

### 5.2 成树衔接

- `track.build` 骨架 + AI 挂载建议不变。
- **成功后不修改标签表**。
- 重生节点 / 挂载保留规则沿用 [Capability Track spec](./2026-11-08-capability-track-design.md)。

### 5.3 IPC 增量

本地、不调模型：

| 方法 | 作用 |
|---|---|
| `track.matchBooks({ bookIds? })` | 对指定书或未归类跑打分；高置信已写入；返回 `{ mounted, pending, skipped }` |
| `track.confirmMatch({ bookId, nodeIds })` | 确认待确认项；写挂载，`source=user` |

沿用：`track.getActive`、`listNodes`、`setBookLinks` 等。书架按脉络优先用现有 `listNodes`；若实现时发现差「未归类 ids」等薄字段，可增 `track.listShelfGroups`，须先改本 spec 再扩 `API_SHAPE`。

**明确不新增：** `listSidebarTree`、任何标签归档 IPC。

导入管道：本批成功且有 active Track 时，主进程对零挂载新书跑匹配（不经模型队列）。

## 8. 决策记录

| 决策 | 选择 | 原因 |
|---|---|---|
| 标签 vs 脉络 | 标签原样；脉络在书架主区分节呈现 | 用户修订：不要覆盖标签 |
| 呈现位置 | 主区「按列表 \| 按脉络」，非侧栏双树 | 侧栏标签语义稳定 |
| 分节粒度 | 全树展开；直挂展示；空节点保留 | 看见结构与缺口 |
| 筛选 | 状态×标签×搜索后分节 | 标签继续有用 |
| 书架改挂载 | 本刀不做 | 避免与＋标签抢入口 |
| 新书匹配 | 本地三档；确认后 `user`；仅零挂载 | 减少未归类堆积且不违反 AI 硬规则 |
| 存储 | 只扩 `local`；不动 tags | 与「标签原样」一致 |
